# 🧪 **Research Projects**

### 🚨 **AI-Generated Misinformation Risk Assessment**

A research project focused on **ranking and prioritizing AI-generated misinformation threats under uncertainty** using a hybrid decision-making framework.

**Research Components:**

* Dempster-Shafer / Evidential Reasoning (DS/ER)
* Belief Rule Base (BRB)
* Analytic Hierarchy Process (AHP)
* TOPSIS
* Multi-Criteria Decision Making (MCDM)
* Uncertainty-aware risk assessment
* Threat prioritization

**Objective:**

> To identify which misinformation threats should be addressed first when multiple threats exist and resources for mitigation are limited.

**Repository:**
👉 `AI-Misinformation-Risk-Assessment`
